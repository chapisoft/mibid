# MIBID BACKEND APPLICATION SERVER

Mã nguồn dịch vụ Backend cho hệ thống Mibid:
- **Ngôn ngữ & Framework:** Java 17, Spring Boot 3.x
- **Kiến trúc:** Hexagonal Architecture (Ports and Adapters) & Domain-Driven Design (DDD)
- **Cơ sở dữ liệu:** PostgreSQL 15+ (Row-Level Security)
- **Bộ nhớ đệm & Khóa phân tán:** Redis 7 (Redisson)
- **Kho lưu trữ tài liệu:** Amazon S3 / MinIO
